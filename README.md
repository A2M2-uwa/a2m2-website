# A²M² website

Static website for **A²M² — AI Augmentation in Modern Medicine**, a research group in the Department of Computer Science and Software Engineering at The University of Western Australia.

The site has no framework, package manager or build step. It is designed to deploy directly to GitHub Pages, Netlify, UWA web hosting, or any ordinary static web server.

## Pages

| Page | File | Purpose |
| --- | --- | --- |
| Home | `index.html` | Group mission, research themes, co-directors, recent work and news |
| Research | `research.html` | Methods, clinical applications and collaborators |
| Team | `team.html` | Equal co-director profiles and group recruitment message |
| Publications | `publications.html` | Searchable and filterable selected publications |
| Opportunities | `opportunities.html` | Student and collaborator pathways |
| Contact | `contact.html` | Contact routes, collaboration guidance and location |

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8765
```

Then open [http://localhost:8765](http://localhost:8765) in a browser. Stop the server with `Ctrl+C`.

## First things to change before publishing

### 1. GitHub Pages production URL

The website is configured for the supplied GitHub Pages project URL:

```text
https://a2m2-uwa.github.io/a2m2-website/
```

The canonical URLs, Open Graph metadata, `robots.txt`, sitemap and web manifest are configured for that project path. If the group later receives a UWA or custom domain, replace `https://a2m2-uwa.github.io/a2m2-website` in the page metadata, `robots.txt` and `sitemap.xml` with the final HTTPS domain.

### 2. Confirm contact details

The contact page uses `ghulam.hassan@uwa.edu.au`, found on UWA’s A²M² research-degree project listing. Add or replace direct contact details for Dr Naeha Sharif only after confirming the preferred public address.

### 3. Review publication wording

`publications.html` intentionally contains a selected set of source-linked work, not a complete CV. Add new items near the top and keep the attributes in place so filtering continues to work:

```html
<article class="pub" data-year="2026" data-type="journal">
```

Allowed `data-type` values are `journal`, `conference`, `preprint` and `book`. The year filter currently has buttons for `2026`, `2025`, `2023` and `earlier`; add a button if you introduce a new year.

## Updating regular content

### Add a news item

In `index.html`, copy one `<article class="news-item">` block. Place it above older entries and update both the machine-readable `datetime` value (`YYYY-MM-DD`) and visible date.

### Add a person

1. Put the original photo in the project root.
2. Add a face-centred square web crop to `assets/img/team/`.
3. Copy a profile `<article>` in `team.html`.
4. Write specific alt text, role, biography and profile links. Do not create placeholder people.

The supplied originals remain in the project root:

- `naeha_profile.jpg`
- `Mubashar_Profile.jpg`

Their deployed profile crops are generated by `tools/make_team_photos.py`.

### Update the logo

`FullLogo_NoBuffer.png` is the master logo source. It has an opaque black background, so do **not** upload it directly as a replacement website image. After replacing it, run:

```bash
python3 tools/make_assets.py
```

This regenerates transparent versions, browser icons and `assets/img/og-image.png`. The script preserves edge quality by doing correct alpha handling.

### Director photographs

After replacing either source photo, adjust the crop rectangle in `tools/make_team_photos.py` if needed and run:

```bash
python3 tools/make_team_photos.py
```

## Optional hero motion

The home page is intentionally static for now. A 6–8 second, silent **WebM** loop is preferable to a GIF: use a slow purple-to-teal gradient sweep through the logo ring, with softly pulsing circuit nodes. Keep the central profile and hands still, include a static poster image, and respect `prefers-reduced-motion`. Avoid patient data, identifiable scans and rapid/flashy motion.
